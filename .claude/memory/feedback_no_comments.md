Do not add comments to code unless the user explicitly requests them.

**Why:** User confirmed this is their preference — well-named identifiers should speak for themselves. Comments were added unrequested and then removed.

**How to apply:** Write comment-free code by default on every edit. If a comment seems useful, use a better name instead. Only add comments when the user says "add a comment" or similar.
