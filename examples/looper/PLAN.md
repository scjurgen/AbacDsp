# Looper

## support various recording modes
 - free recording, when triggered (auto threshold or button) stops when recording pressed or play
 - Preset Number of bars, on trigger (auto threshold or button) will start recording with the beat
 - Count in: will play 1 or 2 bars of metronome, then start recording automatically, stops on bar or with Preset Number of bars

## UI
- Show number of bars and current play position: 1.1 1.2 1.3 1.4 2.1 2.2 etc.
- visualise current bar with an overlay
