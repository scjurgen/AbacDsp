# DSP Modules Used by Examples

Which headers under `src/includes/` are actually pulled into example plugin
builds (`examples/*/src/`), split into three tiers:

1. **Directly used** - an example `#include`s the header itself.
2. **Indirectly used** - no example includes it, but a header an example
   does include pulls it in via its own `#include` chain.
3. **Not used** - not reachable from any example by either path.

Generated by grepping `examples/*/src/**` (without `unittests/`) for direct
includes, then walking the `#include` graph inside `src/includes/` (excluding
`<...>` / 3rdparty includes) to a fixed point to find the indirect set. A `.cpp`
next to a header (`ResoGenerator.cpp`, `WaveTableStorage.cpp`) counts with that
header. Covers all 21 examples and 212 headers: 92 direct, 85 indirect,
35 not used.

## Notes

- `Modulation/Wow.h` and `Modulation/Flutter.h` come in through `Delays/VariSpeedTapeDelay.h`
  (the tape-speed model), `Delays/WobbleDelay.h` and the vibrato block processor.
- `Numbers/PrimeDispatcher.h`, `Approximation.h` and `BulgeControl.h` are pulled in by the reverb
  (`FdnTank*`) and diffuser code.
- `SamplerateConverter` is used 4 of 5: `SrPushConverter.h` and `Filters/Sinc/SincFilter.h` come
  along via `InternalRateNormalizingProcessor.h`, which every example includes, and
  `UpDownSampler.h` via the organic chorus and the Pathfinder tape node. Only
  `SrPullConverter.h` stays unreferenced.
