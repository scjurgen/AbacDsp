# DSP Modules Used by Examples

Which headers under `src/includes/` are actually pulled into example plugin
builds (`examples/*/src/`), split into three tiers:

1. **Directly used** - an example `#include`s the header itself.
2. **Indirectly used** - no example includes it, but a header an example
   does include pulls it in via its own `#include` chain.
3. **Not used** - not reachable from any example by either path.

Generated by grepping `examples/*/src/**` for direct includes, then walking
the `#include` graph inside `src/includes/` (excluding `<...>` / 3rdparty
includes) to a fixed point to find the indirect set.

So, to your specific guesses: `Modulation/Wow.h` and `Modulation/Flutter.h`
are indeed used (via `VariSpeedTapeDelay.h`, tapelooper's tape-speed model),
and `Numbers/PrimeDispatcher.h`/`Approximation.h`/`BulgeControl.h` are pulled
in by the reverb (`FdnTank*`) and diffuser code. `SamplerateConverter` ends up
3-of-4 used once you follow the chain: `SrPushConverter.h` and
`Filters/Sinc/SincFilter.h` come along for the ride via
`InternalRateNormalizingProcessor.h`, which every example includes. Only
`SrPullConverter.h` stays genuinely unreferenced.

## Not used by any example, direct or indirect

These headers exist in `src/includes/` but no example reaches them by either
path. Most are alternative/older implementations superseded by what's listed
above (e.g. `Sampler/SamplePlayer.h`/`SlicePlayer.h` vs. the `SamplePlayerBasic.h`
+ `SliceLibrary.h` combination actually used), or are exercised only by unit
tests.
